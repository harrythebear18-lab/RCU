## 🛠️ Installation

### **🔧 Admin Quick Setup (Recommended)**
```bash
# Clone the repository
git clone https://github.com/harrythebear18-lab/Homelab-Tools.git
cd Homelab-Tools

# Auto-configure for admin systems (Windows 10/11)
cd "Core Services"
python admin_auto_config.py

# Launch admin homelab with auto-configured settings
python admin_startup.py
```

### **Standard Setup**
```bash
# Clone the repository
git clone https://github.com/harrythebear18-lab/Homelab-Tools.git
cd Homelab-Tools

# Run automated installer (Windows 10/11)
Install_Homelab.bat

# Launch the unified portal system
Launch_Homelab_Portal.bat

# Or run portal directly
python Core Services/homelab_portal.py
```

### **Manual Installation**
```bash
# Install required packages
pip install -r requirements.txt

# Install optional packages for full functionality
pip install flask flask-cors  # For REST API
pip install cryptography     # For security features
pip install schedule          # For automation framework
pip install pillow            # For screen sharing
pip install psutil            # For system monitoring
pip install GPUtil            # For GPU monitoring (NVIDIA)
```

## 🌐 Architecture

### **Port Configuration**
- **30000** - Portal main port (TCP)
- **30001** - Network discovery (UDP)
- **30000-31000** - Dynamic port allocation range
- **8080** - REST API and mobile interface

### **Portal Setup**
```
Machine 1: Portal Server (Port 30000)
Machine 2: Portal Client (Port 30001)
```
